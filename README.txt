# Sahar Romantic Website ❤️

Built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap 5.3

## Run

Just open `index.html` in your browser.

## Customize

### 1. Relationship date
Open `script.js` and change:
`const startDate = new Date("2025-06-14T20:00:00");`

### 2. Photos
Replace each `.memory-placeholder` in `index.html` with:
`<img src="assets/photo1.jpg" alt="Our memory">`

Then add styling if needed.

### 3. Text
Edit the story and love letter directly in `index.html`.

The design uses a wine / rose / cream palette with floating hearts,
sparkles, scroll reveal animations, heartbeat effects, and a final love modal.
